redaction carousel maker

Write the post in plain text. Get slides with a lime highlighter on the point and a redaction bar on the beat you would rather not say.

Each slide is a 1080 x 1350 PNG, the 4:5 size for carousels. Wait for the fonts to load if the first render looks plain.

The format

SlideFields
coverkicker, headline, caption (optional), grid: yes (optional notebook grid)
pointheadline, kicker (optional), body (optional), source (optional)
figurekicker, headline (optional), unit, source, and one row: label | value per bar. Add | hero to highlight one bar
conclusionheadline, lead, kicker (optional), source (optional)
signofffootnote, line (optional)

*words* puts a lime highlighter behind them. [[words]] hides them behind a redaction bar with a lime tab. Use one highlight per slide: if two things are highlighted, neither is. Never redact a number the slide depends on.

Read this before you post

Replace the placeholder numbers. The sample figure is not data. Never publish invented numbers.

The look is the ben.j.ads kit. Paper ground, condensed lowercase headlines, lime as a mark and not a ground, square corners. The wordmark is the supplied file and is not retyped.

Check the export. Text wraps by width and long headlines can run past six lines. Shorten them if a slide looks crowded.
